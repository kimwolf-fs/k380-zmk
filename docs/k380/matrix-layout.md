# K380 物理按键矩阵坐标

**状态：** 已记录硬件提供的 RC 对照表；待实板逐键测试确认。

**用途：** 本文档定义物理按键与 K380 逻辑矩阵坐标的对应关系。它与
[`pinmap.md`](pinmap.md) 配合使用：pinmap 定义 `R*`、`C*` 网络连接到 SoC 的 GPIO，
本文档定义每个物理按键连接到哪个 `(row, column)`。

**相关文档：**

- [`pinmap.md`](pinmap.md)：矩阵网络到 nRF52840 GPIO 的电气分配。
- [`hardware-contract.md`](hardware-contract.md)：与矩阵共同构成 K380 的板级硬件契约。

## 坐标约定

- 矩阵尺寸固定为 8 行 x 15 列。
- 坐标格式为 `RC(行, 列)`，行范围为 `0-7`，列范围为 `0-14`。
- 当前共有 80 个有效按键；其余 40 个矩阵坐标未使用。
- 本文档是后续 matrix transform 和默认 keymap 的硬件输入，不替代实板逐键测试。

## 硬件验证要求

使用 SWD 烧入矩阵诊断固件后，必须逐键确认每一个按键只上报本文档定义的
`RC(行, 列)`。验证记录应包含 PCB revision、测试日期、测试固件提交和异常项。

发现错误时，应同时修正原理图或网表、本文档以及后续 matrix transform；不得只修改
keymap 规避错误的矩阵坐标。
